
# 📱 Task Manager App

A simple, fast, and beautifully designed **Flutter Task Manager App** featuring **8 customizable themes**, smooth animations, and secure offline storage using Hive.
Built with clean architecture and powerful **BLoC state management**.



## ✨ Features

### 🎨 **8 Beautiful Themes**

* **4 Light Themes:**

  * Blue
  * Pink
  * Green
  * Orange

* **4 Dark Themes:**

  * Blue
  * Pink
  * Green
  * Orange

Users can switch between themes anytime for a fully personalized experience.

---

## 📝 Task Features

* **Create tasks**
* **Edit tasks**
* **Delete tasks**
* **Local storage with Hive**
* **BLoC state management** for predictable and scalable state flow
* **Organized UI for smooth task handling**




## ⚡ Quick Actions

Supports native **Quick Actions** for faster task access directly from the home screen:

* **Add Task**
* **View Tasks**

Perfect for quickly adding a reminder without opening the app manually.



## 💾 Local Storage

The app uses a high-performance local database:

* **Hive**

  * Stores task data efficiently
  * Fast, lightweight NoSQL storage

* **SharedPreferences**

  * Stores theme preferences
  * Stores user configuration



## 🎬 Animations & UX

Smooth and modern animations powered by:

* **Lottie animations**
* **Animated loading widgets**
* Clean transitions for a polished user experience
